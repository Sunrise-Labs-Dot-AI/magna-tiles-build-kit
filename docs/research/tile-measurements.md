# Magna-Tiles Photo Measurements

Generated by `scripts/measure-tiles.py` from the ten overhead calibration photos.

Calibration uses the four 10 mm black fiducial centers A=(10,65), B=(205,65), C=(10,255), D=(205,255) to compute a pixel-to-sheet-mm homography per image.

Note: `opencv-python` could not be installed in this network-restricted run, so the script used its numpy + local `sharp` fallback for image IO. The measurement geometry and thresholds are in the script and remain reproducible; if OpenCV is later available, the same script will prefer it for image IO.

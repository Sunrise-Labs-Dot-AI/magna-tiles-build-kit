## Independent plan review and implementation contract

Claude Opus was attempted once and failed with expired OAuth. Fresh GPT-5.5 review (`runs/reviews/contact-seating-plan-review.txt`) identified two implementation blockers, both addressed by this explicit contract:

- `gravitySeat: { releaseHeight }` is an operation, with a bounded vertical release offset from the existing target pose. Its moving IDs and one insertion hand are the operation's; installed obstacles are all prior parts. The only eligible new contacts are the target graph's moving-to-installed edges. The release path and full-size fingertip withdrawal are checked at the raised pose.
- A separate gravity simulation receives the complete present build with every new cross-module connection removed. It validates the installed and moving components individually before allowing their temporary disconnection. Existing joints remain active, moving parts are dynamic, at most one installed support panel is fixed, and CCD is enabled. No distant or early joint creation. Record actual per-step geometry and return it only after the unchanged 90-step rest criterion and actual finite-edge closure, followed by an ordinary connected support/release trial.
- The full-stage floor remains fixed; release height is bounded below the unchanged displacement ceiling. Displacement is measured against the target pose, so a release cannot excuse a collapsed result. Unsupported/missed/near contacts fail. Actual trajectories are retained for preview; no authored-pose reset.
- Rotation is a separate subsequent operation; existing transfer rejection remains until a bounded orientation trajectory and one-panel dynamic carry have positive and adversarial tests. Implement seating and source measurement first; do not label a rotated source stage complete from snapshots.
- Source acceptance is one useful final view reserved from fitting per the user's definition, with historical/fresh status separately reported. This rule correction does not turn the current observations into a source pass: complete coverage and unchanged pixel limits are still needed. Implement that correction separately with its own explicit review and tests.
- Original photo measurements and newly inspected construction frames are fit evidence only. Archive old observation/ledger/lock artifacts before any fit-evidence update. Never relabel inspected bytes fresh; any future blind test needs a pre-inspection freeze and reservation. This increment does not modify scored holdout pixels or source replica geometry on the basis of a failed check.

# Native three-panel folding probe

## Decision this experiment must inform

The jet's first body ring is visibly folded from three connected square panels. The existing carry API measures a rigid component and rejects motion across retained internal joins. The geometric diagnostic also finds intersections along the current ideal hinge-axis path at every tested initially attached gap. Before designing an articulation controller or altering the physical model, measure what the current native solver actually does with one ungripped middle panel between two explicit end-panel grips.

This is an off-path physics diagnostic. It must not edit production geometry, source records, the observation lock, runtime constants, joints, collision rules or the numerical profile. Execute it only after the active qualification simulations finish, with no competing heavy run. It is not a substitute for completing the40-piece jet or a source assembly certificate.

## Fixed protocol

- Initialize three catalog small squares in a vertical open strip, with bottom edges on a fixed table. Use the actual two initial joints produced by the current physics model. This initializes a fixture; it does not claim the strip's individual assembly has been verified.
- Test initial gaps.09 and.21 inches, both fold directions, and seeds0/17/53:12 native rows. These are declared diagnostic choices, not measured source gaps or a search for a passing setting. Include a.36-inch separated control that must fail exact initial closure before any native motion; do not run or accept it as attached.
- Use a bespoke off-path `createEngineWorld` loop. Do not route this through `simulateHeldMotion`, which correctly rejects this articulation. The root/end panels have explicit accessible fingertip grips. Assert actual modes at every native step: root `Fixed`, middle `Dynamic`, terminal `KinematicPositionBased`. No corrective forces, steering, damping changes, extra supports or unrecorded clamps.
- After configuring these grips, call the existing `perturbFirstRelease` exactly once on the middle panel, at its index in the declared body order, with seed0/17/53. Record state before grips, state after grips but before perturbation, and state after perturbation, including pre/post velocities and the release-perturbed marker. Seed rows represent the existing velocity uncertainty; they are not identical labels or initial-position perturbations. No further state reset/reseeding is permitted.
- Record each installed joint's id, from/to ids, type, native local anchors and local frames, model local anchors/axis, `secondAnchors` presence, and actual enabled limits/minimum/maximum. Derive its initial world anchor/axis using the native body pose and joint frames, recording any two-end anchor discrepancy from float32 conversion. Require the expected two revolute joints. Define a canonical two-link articulation from the open strip toward the equal-panel triangular ring: both relative link turns reach120 degrees. The distal hinge target frame moves with the ideal articulated middle pose; compose its relative rotation with the proximal rotation to obtain the terminal-panel target. The corresponding middle-panel pose is a measurement target only. The native solver, never the target pose, moves the middle panel.
- Use a bounded10-second motion after a short stationary initial interval, check command speed against the existing2in/s and1rad/s limits, and preserve the actual initial state. The motion rate and ideal angles are fixture geometry, not source-measured hand motion. Reject malformed axes, missing/extra joints, invalid initial contacts or inaccessible grips.
- Keep the current native collision timestep. At every native step observe the real geometry, actual modes, existing joint identities/frames, popped joints, ground/solid failures and swept fingertip clearance. Compute an explicit maximum catalog-prism-vertex residual between each actual panel and its corresponding articulated target, outside `engine.maxDisplacement()`. Compare this residual with the unchanged `MAX_STANDING_DISPLACEMENT`; the engine's initial-pose displacement is recorded but is not a deviation criterion for intended motion. Do not update engine displacement targets or apply one rigid transform to the whole chain. Record the first failure and preserve its actual state.
- Check both authored and native initial contact/clearance, and record any native float32 boundary rejection as a setup result without attempting motion or silently changing the gap. The12 declared rows are required even if a row fails before native integration; distinguish attempted/native-step counts from protocol coverage.
- Record initial/terminal native state, ordered trajectory digest, native step counts, actual timestep/settings, maximum articulated-target error, motion samples including the failure/terminal pose, and exact terminal root-to-end contact if the commanded trajectory completes. Do not add the third joint or grant a release/assembly pass in this diagnostic. A later construction implementation must independently earn that join, withdraw both hands and establish free rest on all seeds.
- Pin the probe script and starting runtime hash; reject a changed runtime/script at the end. Checkpoint only completed rows and mark overall completion separately. Preserve each failure as data; diagnostic exit0 only means the declared experiment completed.

## Review and interpretation

Independently review this protocol before implementation/execution, then review the concrete probe and full results before using them to choose a controller or model change. Type checking and focused lint are required. No whole-project test repeat is needed merely to add this off-path diagnostic, and its execution must not compete with current timed qualification.

If native motion fails, localize whether collision, joint break, target deviation, finger clearance or invalid state caused the first failure. If it completes, inspect actual terminal contact and retained joints rather than inferring ring closure from the command. Either outcome is evidence for the next implementation; neither certifies the source, physical magnet calibration, free release, complete jet assembly or final fidelity. No new larger gap or relaxed threshold may be introduced as a repair without source/material evidence and a separately reviewed physical-model change.

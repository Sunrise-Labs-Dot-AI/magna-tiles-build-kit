## Hypothesis and limits

The production hinge fixes one shared mid-plane axis; the two independently tested surface-axis alternatives each favor one fold direction. Proposal: replace that infinite-stiffness geometric constraint in an isolated experiment with two finite, zero-rest-length point springs on the declared edge. Tile solids supply contact; the point couplings allow the seam to translate and roll while retaining attraction. Neither spring takes a desired panel pose, fold direction, target angle or pivot. This is a phenomenological compliance hypothesis, not a measured magnetic-force law. A Hookean spring is not the far-field force curve of a real magnet.

Use the two existing template locations per catalog small-square edge (fractions0.22 and0.78). Their metal-center accuracy is unmeasured. Anchors remain fixed in each body's immutable reference frame. Match the two opposing point sets once at installation by minimum total squared distance, considering both bijections; record the choice and reject a geometric tie instead of selecting from the target fold. The first prototype covers equal small-square edges only. It is not a production restriction or a substitute for the eventual general seam and complete builds.

Declare the current assumed edge stiffness16 N/in and damping0.45 N/(in/s) as experiment inputs, split equally across the two points. They previously parameterized a break heuristic; reusing the numbers does not constitute force calibration or proof of equivalence. For native inch/kg/second units, multiply force magnitudes by39.37007874015748 inches/metre. Thus each native point spring has stiffness314.96062992125985 kg/s² and damping8.858267716535433 kg/s. Rest length is zero. Keep total edge force threshold5.8 N and separation threshold0.42 in as explicit assumed finite-retention bounds; these values are not fitted to source success. Keep gravity, masses, catalog solids, friction, contact profile, solver iterations, collision/closure limits and physical durations unchanged.

For point displacement d and point relative velocity v, spring force on A points toward B with elastic part k*d. The zero-rest spring's damping is expected along its radial direction, c*dot(v,n)*n; confirm actual native semantics before assuming it. Total coupling wrench must obey equal/opposite action and central-force torque balance. Estimate tensile force for breaking with the original SI-force constants: for each point, max(0,8 N/in * distanceInches +0.225 N/(in/s) * radialSeparationSpeedInchesPerSecond), then sum both points in newtons and compare to5.8 N. Equivalently a native-force sum must be compared to5.8*ENGINE_UNITS_PER_METER, never5.8 directly. Remove both couplings together when that total exceeds the bound or either actual pair distance exceeds0.42 in. Preserve broken connection identity; never reattach during the same experiment. If native spring semantics differ, report the mismatch and revise the model specification before a tile-fold run, rather than silently changing constants.

### API preflight correction, before any force result

The first two archived attempts stopped before stepping a coupon. Additional mass properties require the documented `recomputeMassPropertiesFromColliders()` refresh before querying them. The pinned Rust wrapper's `jointType()` inspects only `locked_axes`; `SpringJoint::new` has no locked axes and consequently reads back as Generic (6), although the authored descriptor is Spring (4). Assert and record both separately, together with descriptor parameters and queried immutable anchors. A Generic tag alone cannot establish a spring, so every original force, damping, conservation, invariance and energy bound remains mandatory and unchanged. No native runtime patch follows from this wrapper classification limitation. This correction and the executable code still require independent review before any finite-tile experiment.

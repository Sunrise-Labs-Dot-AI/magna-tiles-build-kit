Full engineering loop: this changes assembly pose proposals. Keep all physical gates, geometry and source observations fixed. No production promotion or complete-replica claim.

The existing proposal search returns the first pose below the .03-inch dynamic failure allowance. It can therefore introduce a penetrated solid seam and then freeze its relative offset with new hinges.

This replay is not assembly evidence and cannot select a source-specific correction.

Use the complete, containment-aware SAT already used by the independent sweep guard. Check all cross solids, including non-neighbors. Do not change installed panels, the moving module's internal deformation, dimensions, orientation, or constraints. Keep the existing closure, insertion, hand, floor, displacement and later dynamic checks. Do not reject existing within-component elastic/numerical overlap merely by translating that component. If no proposal passes, fail with an explicit reason, not an automatic extra support or solver change. The tighter target requirement is not a relaxed runtime tolerance.

## Strict-target experiment did not generalize

The first fresh run with the strict target filter fails while adding the lower wedge deck: no member of the unchanged translation grid simultaneously has zero cross-solid overlap and the existing edge closure. A finer and wider diagnostic grid also found no such target. Reordering the original grid by distance to the support-aligned mean does not resolve it. No runtime tolerance or source geometry changed, and no source assembly pass is claimed.

Revised proposal for review: rank nonintersecting docking targets ahead of the original overlap-tolerant targets, then prefer the smallest displacement from the support-aligned mean. Preserve the original complete geometry, closure, hand, insertion and mandatory connected/free dynamic checks. An original-range target can be considered only after every clear proposal fails an existing check; it earns no acceptance merely by being proposed. Record its measured target cross-penetration explicitly. This is candidate ordering, not a new physical pass. It retains the old bounded .03-inch runtime allowance and lets actual settling decide whether a shallow transient resolves or leaves an incompatible constrained seam. Prohibit targets above the original raw limit and preserve all dynamic solid failures. Do not add a prepared-module or source-ID exception.

Acceptance remains a known viable clear correction that must be selected over a penetrated mean, blocked/contained targets that cannot pass the original limits, preserved within-component state, and full fresh three-seed construction with unchanged rest and overlap gates. The cost is that the target proposal itself is not a zero-overlap certificate; the separate dynamic assembly evidence remains the authority. The advantage is retaining existing physically settled constructions while avoiding unnecessary seam strain whenever the bounded search supplies a clear alternative.

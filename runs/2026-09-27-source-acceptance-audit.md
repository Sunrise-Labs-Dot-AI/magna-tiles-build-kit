# Source acceptance capability audit

This is a code audit and next-increment boundary, not a replica certificate or an implemented plan. The numerical integration remains frozen during its full structural benchmark.

## Observed gap

`evaluateReplica` initializes `replication` to `not-verified` and never assigns `simulation-verified`. Its fidelity and settled-shape checks intentionally return only fail/unverified because present sparse landmarks do not establish all panels, joins or the complete settled shape. The report writer also hard-codes the absence of accepted replicas and an exit failure outside report-only mode. These are real capability gaps: a successful future source reconstruction cannot yet be accepted by the current executable path. Simply changing these labels would be false acceptance.

Existing source-piece accounting can establish a complete reviewed stage set, but none of the current records does. Point projection, candidate freeze and independent-view history checks are separate and do not establish complete geometry on their own. Material calibration is always unverified and must remain distinct from simulation acceptance. Static display builds need an explicit, source-bound functional applicability decision; an arbitrary missing route cannot waive ramp function. The current small ramp function check can pass an explicitly inferred route: eventual source acceptance must also bind the demonstrated path, launch, lane count and turns to reviewed footage evidence. A passing car trial over a proposed path is insufficient.

## Evidence-led next increment

First finish and preserve the current numerical integration, then replay the unchanged compact medium hypotheses before changing their geometry. Improve the small ramp primitive from declared fitting/construction frames while preserving panel size and inventory. Derive an explicit source constraint record from real observations before designing a general positive acceptance API. It must cover installed panel identities, visible poses and joins, and the evidence that constrains each occluded panel; a BOM remainder or candidate-authored role cannot fill a hidden pose. Underconstrained placements remain unverified. Preserve distinct construction stages.

Before implementing that source contract, independently review the concrete measured example and its acceptance criteria. Add positive acceptance only once the evaluator can recompute complete source constraints, useful independent final-view agreement, all-seed release/settled shape, actual individual-panel assembly, and applicable passive car behavior. Physical calibration remains separately labeled. Adversarial mutations must reject omitted/extra panels, wrong joins, hidden-pose changes, collapsed post-release shape, stale/tuned holdouts, incomplete stages and missing ramp trials. Reports and exit status then derive from those recomputed checks, never from a caller-supplied success label.

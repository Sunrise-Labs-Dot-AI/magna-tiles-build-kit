# Conditional exact-pose collision-check reuse

Proposal, not implementation. Follow the full engineering loop because this touches the collision verifier. The finer-contact 216-cell experiment is still running and its hashed code remains frozen. This plan cannot select a contact profile or alter the experiment. Implement only after a complete independently reviewed numerical profile qualifies and its actual unchanged structural benchmark demonstrates that performance work is needed to preserve the existing computation budget.

## Motivation and narrow proof

`createEngineWorld` samples state and checks the swept panel solids before native integration and after every native step. The next pre-step check often sees exactly the preceding endpoint again; sleeping poses can also remain identical. The current code constructs fresh prism poses and runs pairwise swept-solid checks for each such observation. The previous five-step staircase took about 154 seconds against a fixed four-minute limit at the original collision rate, so an increased native sampling rate creates a concrete budget concern. This is a risk, not a measured failure under a future setting.

Proposal: within one EngineWorld only, reuse the successful certification of the immediately preceding endpoint when the new entire ordered solid state is exactly identical. Initially retain normal prism construction; optimize only the repeated pairwise proof. The previously certified endpoint contains the same solids, identifiers, floor and tolerance, so the new zero-motion interval introduces no new penetration. The prior interval's measured peaks and failures have already been applied. This is exact equality, never a positional epsilon, sleep flag, velocity threshold, time interval or connected-group heuristic.

Require identical body count/order/IDs and catalog shapes plus all finite geometric values the checker consumes: prism vertices, position, rotation, radius, bounds, edges and normals. Compare numeric values exactly (including signed zero where relevant). Do not keep references to mutable current data as the sole identity check. Missing, changed, reordered or nonfinite geometry must take the normal path. Only a completed successful check can authorize reuse; initial checks, restored worlds, failed/uncertified sweeps and changed settings have no inherited cache. Keep floor/tolerance in the reuse identity or make their per-world immutability explicit. Clear/recompute on any applicable change.

Native integration, actual step count and duration, state/finite checks, angular-travel certification before and after integration, joint breakage, penetration/displacement tracking, speed/rest sampling and all caller-level fingertip/grip/deformation checks remain unchanged. Do not add a public acceptance-bypass flag, global cross-world cache, body-mode shortcut, approximate tolerance, support or magnetic constraint. Keep the generic `checkSolidSweep` function and its budget callbacks unchanged. Only this engine-local caller may reuse an already earned exact zero-motion certificate.

## Required evidence

- Exercise the actual engine guard: repeated unchanged poses avoid redundant pairwise work while native steps and samples still occur; an external translation, rotation, tile/shape mutation, body insertion/removal/reordering or other changed checker input prevents reuse. An initial table/overlap failure must still be caught, and a changed pose must still detect table penetration, overlap and uncertified motion at the original step. Nonfinite input must never acquire reuse credit.
- Preserve all existing swept-solid negative controls, full-turn angular-alias rejection, kinematic interpolation, thin-panel/table contact and continued actual-joint/hand/assembly checks. Failure details and measured peak records must not disappear.
- Compare actual numeric trajectories, native counts, failures and rest outcomes with the same selected settings before this optimization, using independent flat/heavy closed-base, moving, failed and supported-transfer cases. Differences require investigation, not rounded equality or accepted drift. Metadata may differ only when explicitly documented.
- Demonstrate the intended repeated-proof reduction using engine-level call evidence and separately measured wall time. Do not claim a speedup from an assumed complexity argument or changed physical duration.
- Rerun the complete 25-outcome structural benchmark under the selected settings. Preserve all 20 constructive successes, five required rejections, four-minute bound and Unlimited semantics. No budget increases or failed-shape exclusions.
- Run independent adversarial code review, affected physical/provenance tests and the full final profile/source/assembly/vehicle/artifact/build/browser checks required by the finer-contact integration plan. The selected numerical profile still needs its complete final configured-rate evidence under the final validator hash. No merge or production promotion.

If exact equality costs too much or does not restore the required budget, retain that measured result and investigate separately. Do not expand this proposal into approximate skipping or weaken the collision proof.
